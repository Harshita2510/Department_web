# Privacy Policy – SGSITS Website Backup

SGSITS Website Backup is an internal tool used only by the SGSITS department to back up the database of its own
department website. It is not offered to the public.

## What it accesses
- **Google Drive** (`drive.file`): only to upload, list and remove the backup files the tool itself creates, in a
  folder of the department's own backup Google account. It cannot see any other files in that Drive.
- **Gmail** (`gmail.send`): only to send backup failure and low-storage alerts to department staff. It cannot read
  any email.

## Data handling
- Backups contain the department website's database and are encrypted before they leave the department's server.
- No data is sold or shared with third parties, and none is used for any purpose other than restoring the website.
- Access can be revoked at any time from the backup Google account at <https://myaccount.google.com/permissions>.

## Contact
For questions, contact the department via the support email shown on the Google sign-in screen.
